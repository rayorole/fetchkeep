# Fetchkeep

**The web, saved for your agents.**

Fetchkeep is an open-source, local-first web retrieval tool for AI agents. It fetches, extracts, saves, searches, crawls and cites web content through a CLI and an MCP server. Core functionality works without an LLM, a paid service or an installed browser.

Work in progress — see the issue tracker for the implementation plan.
