# Fixture provenance

- All fixture pages, PDFs, texts and gold files are generated by `bench/fixtures/build.ts` from text written
  originally for this repository. No third-party content is included. License: Apache-2.0 (same as Fetchkeep).
- Names, places and figures are fictional.
- PDFs are produced by `test/support/pdf.ts` (a minimal PDF writer in this repository) with a Helvetica text layer.
- Dynamic behaviours (robots.txt, redirects, 404/500, redirect loop, slow response, windows-1252 encoding) are
  implemented in `bench/lib/fixture-server.ts`.
- `SHA256SUMS` lists every generated file and `datasets/fixtures.json`; each run records its SHA-256 in `meta.json`.
- Gold texts (`gold/*.txt`) are the visible text of each page's main content, produced by a deliberately simple tag
  stripper in `build.ts` (not by Fetchkeep's extractor) so the reference does not favour any engine.
